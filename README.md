# Kalvis

FM-struck modal synth (VST3 + standalone) by Pie.

**Download:** grab `Kalvis-x.y.z-Setup.exe` from the [latest release](https://github.com/illegalPie/kalvis-releases/releases/latest), run it, rescan plugins in your DAW.

Windows may warn the installer is unrecognised (it is not code-signed): click **More info -> Run anyway**.

Installed copies check this page for updates and offer a one-click install.
